# 🎬 usePopcorn – Movie Search & Watchlist App

**usePopcorn** is a React-based web app that allows users to search for movies using the [OMDb API](https://www.omdbapi.com/), view detailed information, and manage a personal watchlist with custom ratings.

---

## ✨ Features

- 🔍 Search movies using the OMDb API  
- 🎥 View detailed movie information (cast, genre, plot, release date)  
- ⭐ Rate movies with a custom star rating system  
- 🧾 Track watched movies with stats like average rating and runtime  
- ❌ Remove movies from your watched list  
- 💾 Persistent data storage with `localStorage`  
- 🧠 Built-in loading and error states, plus keyboard shortcuts

---

## 🛠️ Built With

- React  
- Custom React Hooks (`useMovies`, `useLocalStorageState`, `useKey`)  
- OMDb API  
- Vanilla CSS  
- LocalStorage  
- React hooks: `useState`, `useEffect`, `useRef`
